# Website Pessoal – Angelita Santos

Este é o repositório do meu website pessoal, onde compartilho um pouco sobre mim, minha trajetória e meus projetos.

---

## Sobre o Website

O site reúne informações sobre:

- **Hobbies** – atividades que faço por prazer e que fazem parte do meu dia a dia.
- **Experiência Acadêmica e Profissional** – minha formação, áreas de estudo e atuação.
- **Literatura** – livros que publiquei e textos autorais.
- **Projetos** – projetos de desenvolvimento disponíveis no meu GitHub.
- **Outras Informações** – contato, redes sociais e curiosidades.

Todo o conteúdo é armazenado em **arquivos JSON**, mantendo os dados separados da interface. Isso facilita a manutenção e a atualização das informações sem a necessidade de alterar o código dos componentes.

---

## Tecnologias Utilizadas

Este projeto foi originalmente desenvolvido em **JavaScript, HTML e CSS** e agora está sendo refatorado para uma stack mais moderna:

- **[React](https://react.dev/)** – biblioteca para construção de interfaces.
- **[Vite 5](https://vitejs.dev/)** – ferramenta de build e servidor de desenvolvimento rápido.
- **[TypeScript](https://www.typescriptlang.org/)** – superset do JavaScript com tipagem estática.
- **[React Router DOM](https://reactrouter.com/)** – roteamento entre páginas.
- **[React Icons](https://react-icons.github.io/react-icons/)** – ícones populares em formato de componentes React.
- **JSON** – armazenamento do conteúdo do site, desacoplado da interface.

## Como Rodar o Projeto

### Opção 1: Clonar o repositório

```bash
# Clone o repositório
git clone https://github.com/angelitasantos/angelitasantos.github.io.git

# Entre na pasta
cd angelitasantos.github.io

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

---

### Opção 2: Criar o projeto do zero

```bash
# Crie o projeto com Vite + React + TypeScript
npm create vite@latest meu-projeto -- --template react-ts

# Entre na pasta
cd meu-projeto

# Instale as dependências
npm install

# Instale as bibliotecas adicionais
npm install react-router-dom react-icons

# Inicie o servidor de desenvolvimento
npm run dev
```
